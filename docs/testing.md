# 测试与覆盖率

在 macOS、Go 1.25 或更新版本上运行：

```sh
go test -count=1 -race -coverprofile=coverage.out ./...
go tool cover -func=coverage.out
go vet ./...
```

GitHub Actions 在 `macos-latest` 上执行相同检查，并要求语句覆盖率至少 60%。2026-10-24 本机非缓存测试的语句覆盖率为 **63.2%**。这是 Go 测试进程的覆盖率，不是安全能力的百分比；端到端测试启动的独立二进制及其探针不会合并进这个数值。

| 范围 | 已验证行为 |
| --- | --- |
| Seatbelt 启动 | 真实 macOS 策略可启动命令；探针检查可读目录、外部文件及 TCP/Unix socket 拒绝 |
| 文件授权 | 多个可写目录、只读目录读/写拒绝、符号链接指向外部文件拒绝、重复路径去重、重叠及宿主敏感目录拒绝 |
| 环境与进程 | 宿主环境变量不继承、子命令退出码保留、运行时目录清理 |
| Broker 与 MCP | 固定请求集合、状态清单、MCP 初始化/工具调用、禁用工具错误、连接关闭后重新检查 |
| GitHub | 模拟 HTTP 服务验证固定身份字段、按 Agent 授权、错误正文不回显、重定向拒绝 |
| 授权状态 | 并发更新、默认关闭、损坏状态拒绝、无凭证或钥匙串查询失败时不打开连接 |

**未自动验证：** 真正的 macOS 钥匙串交互和令牌权限、线上 GitHub 请求、三款 Agent 的在线会话、不同 macOS 版本及长期运行后的资源耗尽。测试不会写入真实钥匙串或调用真实 GitHub API。当前原型不应据此宣称通过安全审计。
